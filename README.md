# Technology for Consumer Rights Awareness

A responsive educational website about how technology supports consumer rights awareness.

## Included
- Consumer rights explained in simple language
- Technology and consumer awareness
- Indian legal context and timeline
- Real-world purchase-to-complaint example
- Smart consumer tips
- Wikipedia context links for further reading
- Mobile and desktop responsive design

## Run
Extract the ZIP and open `index.html` in a modern browser.
No external libraries or paid services are required.
